## Core Capabilities & Engineering Highlights
- **Feudal**: Feudal Meta-Controller (pi_high) and Worker Subagent (pi_low) temporal abstraction
- **Context**: Context compression (Delta s) eliminating main-thread log pollution
- **Bounded**: Bounded credit assignment with 3-attempt retry budget and automatic git rollback
- **Four**: Four deterministic verification oracles (Build, Tests, Lint, Git State) with dual-signal OS notifications
