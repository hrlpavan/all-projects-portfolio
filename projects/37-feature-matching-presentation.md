## Core Capabilities & Engineering Highlights
- **9-slide**: 9-slide interactive web presentation explaining keypoint detection, descriptors, and homography
- **Clean**: Clean reference Python OpenCV implementation of SIFT/ORB matching with Lowe's ratio test
- **RANSAC**: RANSAC outlier rejection and geometric perspective transformation visualizers
- **Responsive**: Responsive keyboard/touch slide navigation with mathematical breakdowns
