## Core Capabilities & Engineering Highlights
- **Real-time**: Real-time 3D orbital mechanics and satellite constellation tracking via Celestrak TLE feeds
- **Live**: Live global ADS-B aviation transponder and USGS seismic event stream fusion
- **Resilient**: Resilient Vite proxy middleware with offline fallback caching for upstream telemetry drops
- **UTF-8**: UTF-8 XML plist and GIS data table transcoding pipeline for zero-error IDE rendering
