## Core Capabilities & Engineering Highlights
- **Heraldic Silhouette**: Strict bilateral symmetry honoring the iconic Albanian flag composition with 9 razor scythe primary blades and 4 grasping sickle talons.
- **Apex Mythical Predator**: Terrifying Twin-Headed Abyssal Wyvern featuring sweeping horns, gaping fangs, barbed venomous tongues, and sinister glowing slit eyes.
- **Pure Black Vector Rule**: Emblem strictly uses `#000000`. Interior details (eyes, fangs, ribs, bone channels) are true vector cutouts via `fill-rule="evenodd"`.
- **Dynamic Background Swapping**: Background rectangle `#flag-background` responds instantly to CSS variable `--bg-color` or XML fill attribute.
- **Interactive Web Previewer**: Standalone zero-dependency HTML5 viewer with real-time color swatches, custom hex color picker, and one-click SVG export.

## Architectural & System Design
The **HRL Corporate Flag** identity system adheres to the high-standard heraldic guidelines and brand architecture of **HRL International Private Limited**:

1. **Compound Negative-Space Architecture**: Replaced coordinate-dependent SVG masks with native SVG compound paths (`fill-rule="evenodd"`), ensuring 100% rendering fidelity across web browsers, Figma, Adobe Illustrator, and Inkscape without coordinate drift.
2. **Parametric Bézier Curve Generator**: Includes `generate_flag.py`, a deterministic Python script mathematically defining every curve, bone channel, and talon geometry.
3. **Dual-Platform Synchronization**: Maintained in complete lockstep across both GitHub and GitLab with matching documentation, vector assets, and MIT licensing.
