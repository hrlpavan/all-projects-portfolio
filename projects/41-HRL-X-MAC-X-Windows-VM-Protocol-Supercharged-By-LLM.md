## Core Capabilities & Engineering Highlights
- **Automated**: Automated prlctl hypervisor orchestration between macOS host and Windows 11 ARM64 VM
- **Cross-OS**: Cross-OS command dispatch executing Windows UiPath RPA workflows from macOS terminal
- **High-bandwidth**: High-bandwidth external SSD media routing for 4K60 DaVinci Resolve Studio timelines
- **Bounded**: Bounded memory allocation guards preventing host swap thrashing during dual-OS workloads
